======================================================================
PROJECT CONTEXT & ARCHITECTURE: INVENTORY MANAGEMENT SYSTEM
======================================================================

[TECH STACK]
- Frontend: React (Vite), Tailwind CSS, Lucide-React, Recharts, xlsx (SheetJS)
- Database & Backend: Supabase (PostgreSQL, Auth, Realtime)
- Currency: Philippine Peso (₱) via Intl.NumberFormat('en-PH', {currency:'PHP'})

[ENVIRONMENT VARIABLES] (SAFE PLACEHOLDERS - real values live only in the
untracked local .env.local; never commit credentials to the repository)
- VITE_SUPABASE_URL=https://your-supabase-project-ref.supabase.co
- VITE_SUPABASE_ANON_KEY=your-supabase-anon-key-here
- DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.your-supabase-project.supabase.co:5432/postgres

[DATABASE SCHEMA]
1. `products` Table:
   - id: UUID (Primary Key)
   - sku: VARCHAR(50) (Unique)
   - name: VARCHAR(255)
   - category: VARCHAR(100)
   - quantity: INT
   - min_reorder_level: INT
   - unit_price: DECIMAL(10, 2)
   - supplier: VARCHAR(100)
   - created_at: TIMESTAMPTZ

2. `stock_logs` Table:
   - id: UUID (Primary Key)
   - product_id: UUID (Foreign Key -> products.id)
   - change_amount: INT
   - type: VARCHAR(50)
   - created_at: TIMESTAMPTZ

[RLS STATUS]
- Row Level Security (RLS) is disabled for development.

[PROJECT STRUCTURE]
- src/main.jsx -> React entry, wraps app in AuthProvider
- src/App.jsx -> layout, sidebar wiring (desktop rail + mobile drawer),
  route guards, quick-filter state, LowStockBanner quick-action handlers
  (handleLocateProduct / handleShowAllAlerts / handleNavigate)
- src/context/AuthContext.jsx -> user, role (Admin/Viewer), login, signup, logout
- src/hooks/useInventory.js -> product CRUD, filters, realtime subscriptions
- src/lib/supabaseClient.js -> Supabase singleton; reads VITE_* env vars,
  console.error when missing, falls back to non-empty placeholder strings so
  builds never crash (no hardcoded project domains)
- src/utils/currency.js -> formatPHP / formatPHPCompact (₱ formatter)
- src/utils/exportExcel.js -> SheetJS workbook builder (typed cells, ₱ number
  format, auto column widths, autofilter) + browser download; replaces old CSV
- src/components/auth/ -> AuthModal (dark-neon login/signup modal form)
- src/components/common/ -> Header (top-left sidebar toggle: Menu icon on
  mobile / PanelLeftClose-Open on desktop), ControlBar (dark amber-bordered
  action card: search, category, quick-filter chips, action group),
  AuthGate, LowStockBanner
- src/components/dashboard/ -> MetricsBar, StatCard (bg-slate-900,
  border-amber-500/20, amber icon accents), AnalyticsView (amber chart palette)
- src/components/inventory/ -> ProductTable (WHITE high-contrast card:
  bg-white text-slate-900 border-slate-200, dark header bar, amber hovers;
  tr id=product-row-{id} for jump scrolling), ProductModal (auto-SKU +
  numeric focus/blur UX), StockLogModal
- src/components/layout/Sidebar.jsx -> primary nav: Dashboard, Analytics,
  Low-Stock Alerts (badge count), Audit Logs. COLLAPSIBLE: desktop rail
  w-64 <-> w-20 icon-only (chevron button at sidebar foot + Header toggle),
  state persisted in localStorage key 'inv-sidebar-collapsed'; mobile keeps
  overlay drawer (Escape/backdrop close, body lock)

[AUTH & ROLE-BASED ACCESS]
- Auth gate: unauthenticated users only see AuthGate (login / signup).
- Roles: `user.user_metadata.role` = "admin" | "viewer".
  * Admin: full read + write (Add, Edit, Delete, stock +/-).
  * Viewer: read-only; write buttons disabled with "Admin access required".
- Signup writes role via supabase.auth.signUp options.data.role.
- Header shows role badge (Admin/Viewer), user email and Logout.
- main.jsx renders <AuthProvider>; App returns AuthGate when no session.

[ACCESSIBILITY & UX RULES]
- Body/label text >= 14px (tailwind fontSize.xs/sm overridden; text-[11px]
  removed). Interactive controls use min-h-[44px] / h-11 w-11.
- Global focus ring: 2px solid #fbbf24 (amber) with offset (index.css).
- Palette: onyx slate-950/900 surfaces, amber-400/500 + yellow accents,
  white data tables for reading contrast; status colors keep 4.5:1+.
- Reduced-motion media query disables animations/transitions.

[VIEW STATES]
- Primary nav lives in Sidebar: "Dashboard" (Inventory Table, default),
  "Analytics", "Low-Stock Alerts" (badge = critical count), "Audit Logs".
  Mobile: Menu button in Header opens overlay drawer; desktop: fixed left
  rail that collapses to icon-only (main content pl-20 collapsed / pl-64
  expanded via lg:pl-* on the App wrapper).
- Inventory table renders as a white high-contrast card; all other panels
  are dark slate-900 cards with amber-500/20 borders and p-6 padding.
- LowStockBanner renders only when quantity <= min_reorder_level items exist.
- Alert Manager toggles highlightAlerts -> amber row highlight in ProductTable.
- "View N Alerts" expands the drawer (chips hidden while expanded); each
  critical product row jumps to it in the table (filters by SKU first).
- "Show all in table" clears search/category, enables highlighting, table view.
- ControlBar quick filters: all | low | out narrow the visible table rows
  (displayProducts in App.jsx) without touching metrics/analytics totals.
