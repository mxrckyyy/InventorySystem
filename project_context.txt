======================================================================
PROJECT CONTEXT & ARCHITECTURE: INVENTORY MANAGEMENT SYSTEM
======================================================================

[TECH STACK]
- Frontend: React (Vite), Tailwind CSS, Lucide-React, Recharts, xlsx (SheetJS)
- Database & Backend: Supabase (PostgreSQL, Auth, Realtime)
- Currency: Philippine Peso rendered as "P120.00" (Intl.NumberFormat('en-PH')
  grouping + 2 decimals, literal P prefix; Excel cells use P#,##0.00)

[ENVIRONMENT VARIABLES] (SAFE PLACEHOLDERS - real values live only in the
untracked local .env.local; never commit credentials to the repository)
- VITE_SUPABASE_URL=https://your-supabase-project-ref.supabase.co
- VITE_SUPABASE_ANON_KEY=your-supabase-anon-key-here
- DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.your-supabase-project.supabase.co:5432/postgres

[DATABASE SCHEMA]
1. `products` Table:
   - id: UUID (Primary Key)
   - sku: VARCHAR(50) (Unique)
   - name: VARCHAR(255)
   - category: VARCHAR(100)
   - quantity: INT
   - min_reorder_level: INT
   - unit_price: DECIMAL(10, 2)
   - supplier: VARCHAR(100)
   - created_at: TIMESTAMPTZ

2. `stock_logs` Table:
   - id: UUID (Primary Key)
   - product_id: UUID (Foreign Key -> products.id)
   - change_amount: INT
   - type: VARCHAR(50)
   - created_at: TIMESTAMPTZ

[RLS STATUS]
- Row Level Security (RLS) is disabled for development.

[AUTH & ROLE-BASED ACCESS]
- Auth gate: unauthenticated users only see AuthGate (login / signup).
- Roles: `user.user_metadata.role` = "admin" | "viewer".
  * Admin: full read + write (Add, Edit, Delete, stock +/-).
  * Viewer: read-only; write buttons disabled with "Admin access required".
- Signup writes role via supabase.auth.signUp options.data.role.
- Header shows role badge (Admin/Viewer), user email and Logout.
- main.jsx renders <AuthProvider>; App returns AuthGate when no session.

[ACCESSIBILITY & UX RULES]
- Body/label text >= 14px (tailwind fontSize.xs/sm overridden; text-[11px]
  removed). Interactive controls use min-h-[44px] / h-11 w-11, except the
  ControlBar toolbar which uses consistent h-10 heights per layout spec.
- Global focus ring: 2px solid #00D06C (emerald) with offset (index.css).
- Palette: obsidian #0B1015 / card #151D24 / border #222E3A, emerald brand
  accents (#00D06C, emerald-400/500), white headings, slate-300 secondary,
  red-400 errors; amber only for stock warnings; status colors keep 4.5:1+.
- Reduced-motion media query disables animations/transitions.

[VIEW STATES]
- Primary nav lives in the hamburger DRAWER (Sidebar.jsx), opened by the
  top-left Menu button in Header: "Dashboard" (Inventory Table, default),
  "Analytics", "Low-Stock Alerts" (badge = critical count), "Audit Logs".
  Drawer works at every breakpoint; main layout has no fixed sidebar and
  uses full width (no lg:pl-* offsets, no max-w cap).
- Inventory view: ControlBar header card (Inventory title + description +
  search) sits above the dark ProductTable card; Analytics view hides
  ControlBar (search/filters only affect the table).
- LowStockBanner renders only when quantity <= min_reorder_level items exist.
- Alert Manager toggles highlightAlerts -> amber row highlight in ProductTable.
- "View N Alerts" expands the drawer (chips hidden while expanded); each
  critical product row jumps to it in the table (filters by SKU first).
- "Show all in table" clears search/category, enables highlighting, table view.
- ControlBar quick filters: all | low | out narrow the visible table rows
  (displayProducts in App.jsx) without touching metrics/analytics totals.
